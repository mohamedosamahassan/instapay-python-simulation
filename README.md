# InstaPay Simulation

A console-based InstaPay simulation built using Python fundamentals.

## Features

- User Registration
- User Login
- Limited Login Attempts
- View Balance
- Link Visa Card
- Deposit Money
- Withdraw Money
- Transfer Money Between Users
- Transaction History
- Logout
